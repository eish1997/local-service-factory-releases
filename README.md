# 本地生活服务图片工厂：软件分发

本仓库用于发布 Windows 安装程序和软件自动更新文件，规则数据在 [规则仓库](https://github.com/eish1997/local-service-factory-rules)。

## 当前状态

源码开发版本为 1.3.0。本仓库尚未发布正式安装包；本地模拟更新测试不代表真实安装升级已验收。

正式发行通过 GitHub Releases 提供安装程序、blockmap、latest.yml 和签名清单。维护端在明确授权构建后生成独立运行安装包，再使用 `python factory.py updates publish` 发布。发布完成并核验前，不提供客户端可用版本指向。

## 使用端更新

软件启动检查更新，此后每六小时检查；验证下载文件后，在正常退出且无后台任务时安装。项目规则独立检查、校验和激活。用户密钥、图片、任务和个人配置保存在用户目录，不随软件发布上传。

本仓库只用于分发，不包含维护电脑的完整源码、私钥、API 凭证或客户历史。
